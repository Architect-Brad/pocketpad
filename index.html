Features

Everything you need. Nothing you don't.

Built from scratch for mobile. No Electron, no bundler, no bloat.

🧠

PocketPad Intelli

Custom IntelliSense engine with language analyzers for 7 languages. Completions, hover docs, go-to-definition, diagnostics — all running locally in Web Workers.

JS/TS Python Go Rust C/C++ HTML CSS
💬

NLP AI Assistant

Ask questions in plain English. The assistant understands intent, detects your language, and generates code, explains errors, or reviews your code — all processed locally.

Code Generation Error Explainer Code Review
▶️

Run Code Instantly

Execute JavaScript in-browser, run Python via Skulpt, compile C/C++ and Go through cloud sandboxes. See output without leaving the editor.

JavaScript Python C/C++ Go Rust
🔀

GitHub Integration

Browse repos, edit files, view Issues and PRs, check commit history, blame view, and branch switching — all from your phone.

Repos Issues Pull Requests Blame

Zero-Build Architecture

No webpack, no Vite, no transpiler. Pure ES modules with lazy-loading. The app loads in under 240KB base — fast on any connection.

ES Modules Lazy Loading 240KB Base

Offline-First PWA

Install to your home screen. Works without internet. Service worker caches everything. Feels like a native app, costs nothing to distribute.
